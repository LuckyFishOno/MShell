# MShell

[English](README.md)

MShell 是 macOS 原生 SSH 客戶端。你可以用資料夾整理常用主機，在同一個工作區開啟終端、透過 SFTP 瀏覽遠端檔案，也能並排查看兩條連線。

## 功能

- **連線管理** · 點一下資料夾即可展開或收合。把項目拖到另一項上方或下方可調整順序，拖到資料夾上可移進去，拖到「根資料夾」可移到最上層。搜尋結果若包含資料夾，也會列出其中的連線和子資料夾。「+」旁可選自訂、名稱升序或名稱降序。依名稱排序時，資料夾排在前面，拖曳只能把項目移進資料夾。切回「自訂」即可恢復原本的順序。用側欄按鈕或 ⌃⌘S 收合或展開連線樹。連線可在分頁或獨立視窗開啟。
- **終端** · 按 ⌘T 開啟本機 shell。要分割畫面，把分頁拖到窗格的任一邊緣，或按 ⌘D 左右分割、⇧⌘D 上下分割。拖到窗格中央會改在該窗格顯示。已連線的工作階段與本機終端可以分割，停在登入表單的分頁要先連線。每個窗格都能再分割，分隔線可以拖曳。

  分割後只占用一個「工作區」分頁，把滑鼠移到分頁上可查看裡面的連線。把窗格標題拖到另一側可搬移窗格，拖回分頁列會拆成獨立分頁。標題旁的 × 會中斷連線並關閉工作階段。分頁多時會等比例縮小，最小只顯示圖示。按 ⇧⌘↩ 放大或還原窗格，按 ⌥⌘I 同步輸入到所有窗格。方塊游標跟著 shell 的輸入位置，滑鼠仍可選取和複製文字。
- **常用指令** · 在右側面板儲存、搜尋單行指令。可先填入選取的終端再編輯，也可確認指令和目的地後直接執行。
- **SSH** · 支援密碼、Ed25519、ECDSA、RSA 金鑰檔及 `ssh-agent` 登入。首次連線時可核對主機指紋。最多串接八台跳板，也可透過 SOCKS4、SOCKS4a、SOCKS5 或 HTTP CONNECT 代理連線。
- **連接埠轉發** · 在 SSH 分頁啟動本機轉發、反向轉發或動態 SOCKS 代理。將規則存入連線設定後，每次連線成功就會自動啟動。監聽範圍限於本機或 SSH 伺服器的回送介面。
- **密碼庫** · 可選用主密碼保護的密碼庫。尚未建立密碼庫時，MShell 會用 Secure Enclave 金鑰保護登入成功的密碼，下次連線時自動帶入。建立密碼庫後，已記住的密碼仍留在這台 Mac。

  密碼庫解鎖期間，連線無須用 Touch ID 或 Mac 密碼驗證。鎖定後，勾選「每次連線都要求 Touch ID 或 Mac 密碼」的連線會再次要求驗證，其他連線使用這台 Mac 記住的密碼。如果密碼只存在密碼庫，當次連線可用 Touch ID 讀取，密碼庫仍維持鎖定。這個功能在每次開啟 MShell 後，首次用主密碼解鎖時啟用。

  密碼庫收合且鎖定時，可按旁邊的指紋圖示解鎖。連線表單若顯示「已存入密碼庫」，點開可用剛輸入的密碼更新資料，也可移除原有密碼。登入前可按「存入密碼庫」先儲存。
- **Secure Enclave 金鑰** · 在金鑰選擇旁按「建立公鑰」。MShell 會在這台 Mac 的 Secure Enclave 建立 P-256 金鑰，並存到 App 的資料夾。如果這條連線還沒選金鑰，會直接套用。建立後按「查看公鑰」可顯示 OpenSSH 公鑰，再複製或重新產生。使用這把金鑰連線無須 Touch ID。
- **儲存登入資訊** · 密碼或金鑰密語驗證成功後，MShell 會記在這台 Mac，下次連線不用再輸入。新連線預設勾選「每次連線都要求 Touch ID 或 Mac 密碼」，既有連線沿用原設定。密碼庫解鎖期間無須再次驗證。

  選擇「已存密碼…」並通過 Touch ID 或 Mac 密碼驗證後，可查看完整清單和使用各筆密碼的連線，也可顯示、複製或刪除密碼。複製的密碼會在 60 秒後從剪貼簿清除。按金鑰旁的 × 並確認後，已儲存的連線會停止使用這把金鑰。若操作當下密碼庫已解鎖，也會刪除該帳號已存的密碼與金鑰密語。下次從連線樹開啟時須重新輸入密碼。若舊版 Secure Enclave 金鑰顯示「需要 Touch ID」，改用 MShell 金鑰可省去金鑰的 Touch ID 提示。
- **重開已儲存的連線** · 在左側連線樹按兩下，會在主視窗開新分頁。主機金鑰若有變更，先查證新指紋，再選「更新金鑰並重新連線」。在終端輸入 `exit` 或 `logout` 會關閉分頁。連線中斷時，分頁會保留，可按「重新連線」。
- **檔案側欄** · macOS 版面的右側會以資料夾樹顯示所選窗格的檔案。遠端連線從伺服器的登入目錄開始，本機終端從這台 Mac 的家目錄開始。選取另一個窗格即可切換目錄樹，按工具列的「檔案」可收合或展開側欄。按遠端側欄標題旁的「上傳」可將檔案傳到選取的資料夾，也可以直接從 Finder 拖入。按滑鼠右鍵可下載、重新命名、刪除或新增資料夾。
- **檔案傳輸** · 雙欄畫面類似 WinSCP 或 FileZilla。左欄顯示這台 Mac，右欄顯示已連線的伺服器，下方是傳輸佇列。可在兩欄之間拖曳檔案，也可按中間的箭頭。資料夾會連同其中的所有內容一起複製。遇到同名檔案時，可選「取代」或「略過同名檔案」。傳輸時會先寫入暫存檔，失敗或取消時會保留原檔。

  在 macOS 版面，用工具列中央的「終端｜檔案傳輸」切換主視窗，上方分頁決定右欄顯示哪台伺服器。在 Xshell 版面，工具列的「檔案傳輸」會像 Xshell 開啟 Xftp 一樣，另開視窗。在 MobaXterm 版面，可繼續使用左側 SFTP 面板，或按面板標題旁的「雙欄傳輸」開啟獨立視窗。獨立視窗可從上方選擇伺服器。
- **匯入連線** · 可先預覽 Xshell 連線資料夾、OpenSSH 設定、MobaXterm 匯出檔（`.mxtsessions` 或 `MobaXterm.ini`）、由登錄檔匯出的 PuTTY 或 KiTTY 連線（`.reg`）、CSV 檔及 MShell 連線檔。匯入會保留資料夾結構，並讀取帳號、連接埠、金鑰、代理與跳板設定。MobaXterm 的 SSH 閘道和 PuTTY 的 SSH 代理會匯入為跳板連線，PuTTY 的連接埠轉發規則也會保留。密碼不會匯入。預覽會列出略過的項目，以及 Windows 金鑰檔等需要檢查的設定。
- **匯出連線** · 可一次匯出所有連線，也可從資料夾的右鍵選單匯出單一資料夾。MShell 連線檔和 CSV 都不含密碼，可以分享給團隊。家目錄內的金鑰路徑會寫成 `~/…`，匯入時會對應到使用者自己的家目錄。CSV 必須包含 `host` 欄位。`folder`（例如 `Team/Prod`）、`name`、`port`、`username`、`protocol`（`ssh` 或 `sftp`）、`identity file`、`proxy type`、`proxy host`、`proxy port`、`jump`（另一列的 `folder/name`，或 `user@host:port`）都可省略。
- **工作區外觀** · 可在右側面板依名稱搜尋 72 組配色，包括 Ubuntu、Kali、GNOME、KDE Breeze、Tango、Linux 主控台配色，以及 GitHub、One Dark Pro、Dracula、Tokyo Night、Catppuccin、Nord、Gruvbox 等熱門 VS Code 主題。所有終端會使用目前的工作區配色，也可在「設定」視窗（⌘,）選擇主題。
- **語言** · 介面提供英文和繁體中文，預設跟隨這台 Mac 的語言。你可以在 MShell 的「設定 › 一般」或 macOS 的「系統設定 › 一般 › 語言與地區 › App」調整同一項設定。MShell 介面會立即切換，macOS 提供的「關於」、「結束」等選單會在下次開啟 App 時切換。
- **工作區版面** · 在工具列最右側切換版面。選擇會立即套用並儲存，三種版面共用連線、配色和工具。
  - **macOS**（預設）使用 macOS 工具列、扁平分頁和浮動窗格，檔案樹在右側。
  - **Xshell 風格**使用圖示工具列、方框分頁，左側是工作階段管理員。網址列可輸入 `ssh://使用者@主機:連接埠`、`使用者@主機` 或主機名稱。終端下方的輸入列可把一行文字傳到目前或所有工作階段。狀態列顯示位址、協定、終端大小、游標位置、工作階段數和 Caps Lock。
  - **MobaXterm 風格**使用大圖示功能列和編號分頁。左側可切換「工作階段」（含快速連線）、「SFTP」和「巨集」（常用指令）。勾選 SFTP 下方的「跟隨終端資料夾」後，每次執行指令，檔案面板就會切到遠端 shell 所在的資料夾。如果 shell 不會回報資料夾，MShell 會在終端輸入一行提示字元掛鉤。終端下方的監控列會顯示這台 Mac 或 Linux 伺服器的 CPU、記憶體、網路、開機時間、使用者數和磁碟用量。

## 從原始碼建置

需要 macOS 14 以上與支援 Swift Package Manager 的 Xcode。目前已在 Apple silicon 上用 Apple Swift 6.4 驗證建置。

```sh
git clone https://github.com/LuckyFishOno/MShell.git
cd MShell
./MShell/scripts/package-app.sh
open build/MShell.app
```

打包指令會建置本機 App，並套用 ad hoc 簽章。

## 從命令列設定版面

```sh
./build/MShell.app/Contents/Resources/bin/mshell layout get
./build/MShell.app/Contents/Resources/bin/mshell layout set mobaxterm
```

可選 `macos`、`xshell`（存成 `terminal`）或 `mobaxterm`（存成 `transfer`），下次啟動 App 時套用。

## 執行測試

```sh
swift test --package-path MShell
```

測試涵蓋終端輸入、連線匯入與儲存、SSH 驗證、跳板、轉發、重新連線及 SFTP。如果有相容的 Xshell 原始樣本，可用 `XSHELL_DIR` 指定資料夾。未提供樣本時會略過這些測試。AppKit 互動測試需要可用的 macOS 桌面工作階段。
