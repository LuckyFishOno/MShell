Third-party Visual Studio Code color themes

Built-in theme extensions from Visual Studio Code 1.144.1 (theme-abyss, theme-kimbie-dark, theme-monokai, theme-monokai-dimmed, theme-quietlight, theme-red, theme-solarized-dark, theme-solarized-light, theme-tomorrow-night-blue) are
distributed under the Microsoft MIT license in vscode-themes-license.txt.

MShell bundles only workbench color values from the following Marketplace extensions. Token
colors, icons and other files are not included.
